# 桌访语料转换

将 `桌访数据_YYYY-MM-DD_至_YYYY-MM-DD_N条.csv` 转为 `语料桌访_1.5版_N条_YYYY-M-D.xlsx`，供四维度「心理学案例采纳奖」语料使用。

## 规则

- 输出 13 列，与语料桌访模板一致
- 按 **下单时间** 从早到晚排序（`未识别` 排最后）
- **会话ID** 重编为 `{批次前缀}-{三位序号}`，批次前缀默认取上级目录名（如 `260608`）
- 字体、列宽、表头与数据行格式复制自 `assets/语料桌访_1.5版_模板.xlsx`

## 用法

```bash
cd 订单与桌访合并/桌访语料转换

../../四维度自动评审/.venv/bin/python convert_corpus.py \
  "/path/to/桌访数据_2026-06-08_至_2026-06-14_467条.csv"
```

输出默认写在 CSV 同目录，例如：`语料桌访_1.5版_467条_2026-6-14.xlsx`

可选参数：

- `--template` 自定义格式模板
- `--output` 指定输出路径
