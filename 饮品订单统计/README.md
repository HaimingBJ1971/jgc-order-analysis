# 万荷饮品/酒水订单统计

按 POS「商品中类」统计饮品酒水销售，输出 A4 纵置 PDF。统计口径与**订单桌访合并**一致（消费团体数，非 POS 原始单数）。

## 统计品类（九类）

**非酒精**（表内前三行）：调饮汁、饮料和水果、茶

**含酒精**（其后六行）：啤酒、白酒、葡萄酒、鸡尾酒、苏格兰威士忌、黄酒

维度合并表顺序：非酒精 → 含酒精 → 九类合计。

## 统计指标

| 列 | 含义 | 分母 |
|----|------|------|
| 团体数 | 含该品类消费团体数 | 统计范围内全部消费团体 |
| 团占比 | 团体数占比 | 同上 |
| 人数 | 对应团体「团体人数」之和 | 统计范围内就餐人数合计 |
| 人占比 | 人数占比 | 同上 |
| 销量 | 商品明细「数量」合计 | — |
| 点购率 | 销量÷统计范围就餐人数 | 一人一杯 = 100% |
| 收入 | 商品明细「菜品收入」合计 | 统计范围内全部商品收入 |
| 额占比 | 收入占比 | 同上 |

## 与订单桌访合并的关系

复用 `merge_order_zhuofang.load_and_process_orders()`：

- 仅堂食；剔除「外点自取」
- 同桌后续补单合并为一消费团体
- 过滤免单、纯零食、纯打包、零散小单、吧台等
- **团体数 / 就餐人数** 与订单桌访合并报告一致（例：260615 万荷 358 团体、1284 人）

| `--start` / `--end` | 否 | 统计周期展示用 |
