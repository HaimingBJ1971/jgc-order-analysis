# 万荷饮品/酒水订单统计

按 POS「商品中类」统计饮品酒水销售，输出 PDF。团体数和人数沿用订单桌访合并结果；销量和收入只统计有收入的饮品商品。赠送、免单、全额优惠不计入。套餐父项不计入，套餐子项只要单独分到了收入，就计入对应品类，使 POS 商品归因收入与店内订单收入闭合。第三方平台外卖目前没有商品明细，暂不归入饮品品类，但计入整体营业额分母。

## 统计品类（十一类）

**非酒精**（表内前五行）：调饮汁、饮料和水果、茶、咖啡、冰淇淋

**含酒精**（其后六行）：啤酒、白酒、葡萄酒、鸡尾酒、苏格兰威士忌、黄酒

维度合并表顺序：非酒精 → 含酒精 → 十一类合计。

## 统计指标

| 列 | 含义 | 分母 |
|----|------|------|
| 团体数 | 含该品类消费团体数 | 统计范围内全部消费团体 |
| 团占比 | 团体数占比 | 同上 |
| 人数 | 对应团体「团体人数」之和 | 统计范围内就餐人数合计 |
| 人占比 | 人数占比 | 同上 |
| 销量 | 商品明细「数量」合计 | — |
| 点购率 | 销量÷统计范围就餐人数 | 一人一杯 = 100% |
| 收入 | POS 店内商品归因收入：`菜品收入 > 0`，排除套餐父项，保留套餐子项 | — |
| 额占比 | 收入占整体营业额比例 | POS 店内订单收入 + 第三方平台外卖已完成订单收入 |

## 与订单桌访合并的关系

团体数/人数复用 `merge_order_zhuofang.load_and_process_orders()`：

- 仅堂食；剔除「外点自取」
- 同桌后续补单合并为一消费团体
- 过滤免单、纯零食、纯打包、零散小单、吧台等
- **团体数 / 就餐人数** 与订单桌访合并报告一致（例：260615 万荷 358 团体、1284 人）

销量和收入按 POS 商品明细统计：只要饮品商品有收入就计入，赠送、免单、全额优惠不计入。套餐父项不计入；套餐子项只要形成收入就计入，用于反映顾客实际获得的饮品，并避免套餐父项与子项重复统计。

## 用法

### 本期 + 同比环比（推荐）

```bash
cd "/Users/jgc/Documents/每周:月工作"

# 周评：环比=上周，同比=去年同 ISO 周
四维度自动评审/.venv/bin/python 订单与桌访合并/饮品订单统计/generate_drink_order_stats_pdf.py \
  --excel "path/万荷店内订单明细....xlsx" \
  --output "path/万荷饮品酒水订单统计_20260615_20260621.pdf" \
  --store "万荷餐厅" \
  --mode week \
  --db 订单与桌访合并/长期订单分析/output/长期订单分析.db

# 月评：环比=上月，同比=去年同月
四维度自动评审/.venv/bin/python 订单与桌访合并/饮品订单统计/generate_drink_order_stats_pdf.py \
  --excel "path/万荷店内订单明细....xlsx" \
  --output "path/万荷饮品酒水订单统计_202605.pdf" \
  --store "万荷餐厅" \
  --mode month \
  --db 订单与桌访合并/长期订单分析/output/长期订单分析.db
```

- **本期**：来自 `--excel`，与订单桌访合并同 pipeline
- **环比/同比**：来自 SQLite 主库（`filter_status=kept` 消费团体），周期规则与「周期对比分析」一致
- 传 `--mode` 时周期从 Excel 自动校验（须为完整一周或完整一月）

### 仅本期（无对比）

```bash
四维度自动评审/.venv/bin/python 订单与桌访合并/饮品订单统计/generate_drink_order_stats_pdf.py \
  --excel "/path/to/店内订单明细2026-06-15+...万荷.xlsx" \
  --output "/path/to/万荷饮品酒水订单统计_20260615_20260621.pdf" \
  --store "万荷餐厅" \
  --start 2026-06-15 \
  --end 2026-06-21
```

| 参数 | 必填 | 说明 |
|------|------|------|
| `--excel` | 是 | 万荷店内订单明细 Excel（本期） |
| `--output` | 是 | 输出 PDF 路径 |
| `--store` | 否 | 报告标题门店名，默认「万荷餐厅」 |
| `--mode` | 否 | `week` 或 `month`；传入后启用同比环比 |
| `--db` | 否 | SQLite 主库；`--mode` 时默认用项目主库 |
| `--start` / `--end` | 否 | 无 `--mode` 时展示用周期；有 `--mode` 时从 Excel 自动推断 |

## 输出结构

### 含 `--mode`（同比环比）

**版式**：A4 **横置**（多列表格需要宽度）。

| 章节 | 内容 |
|------|------|
| 摘要表 | 指标 × 三期（本周/上周/去年同期，或本月/上月/去年同月）**原始数据**，含 POS 店内订单收入、第三方平台外卖收入、整体营业额和十一类收入；不做比率 |
| 摘要说明 | 表下正文，每条以 **【本周说明】** 标注统计口径、POS 单数、人数口径、占比分母（避免与环比/同比列混淆） |
| 一、分品类统计（本周） | 9 列简表，每品类 1 行，**仅本期** |
| 二、分品类同比环比对比 | 每品类 3 行（本周期/环比期/同比期）+ 右侧 6 列相对本期比率（本期=100%） |
| 三、维度合并统计（本周） | 9 列简表，非酒精/含酒精/十一类合计 |
| 四、维度合并同比环比对比 | 同上三行对比结构 |
| 五、口径说明 | 全文口径、整体营业额闭环与数据来源 |

### 仅本期（无 `--mode`）

**版式**：A4 **纵置**。摘要（关键指标 + 【本期说明】正文）、分品类表、维度合并表、口径说明。
