# 订单与桌访合并工具

整合完整订单处理 pipeline（void菜品过滤、合并、人均计算、零食过滤），关联桌访反馈数据（含订单号缺失时的三变量「三选二」智能匹配），检测疑似异常，统计开单人/桌访人排名，生成 PDF + Markdown 合并报告。

## 用法

```bash
python3 merge_order_zhuofang.py \
    --excel "店内订单明细2026-04-24+...xlsx" \
    --csv   "桌探数据_1.5版_42条_2026-04-24.csv" \
    [--store "万荷店"] \
    [--output-dir "./output"]
```

| 参数 | 必填 | 说明 |
|------|------|------|
| `--excel` | 是 | POS 订单 Excel 文件路径（单店数据） |
| `--csv` | 是 | 桌访 CSV 文件路径（含多店数据） |
| `--store` | 否 | 门店名称（万荷店/保利店/湾里店），不传则自动推断 |
| `--output-dir` | 否 | 输出目录，默认为 Excel 所在目录 |

## 输出物

| 文件 | 说明 |
|------|------|
| `订单桌访合并_YYYYMMDD_门店.pdf` | 纵向 A3 PDF 报告（数据总览含百分比列与会员/非会员对比、两步订单公式含吧台过滤、客单价分布、开单人/桌访人统计、重点菜品/新品统计、异常汇总、订单索引含日期列按桌台→日期→时间排序、逐团体详情）；表头统一深藏青底白字；跨天报告文件名为 `_起始日期_结束日期_` |
| `订单桌访合并_YYYYMMDD_门店.md` | Markdown 报告（结论先行，已桌访/未桌访、开单人/桌访人统计、重点菜品/新品、未匹配记录、数据质量说明） |

## 依赖

```bash
pip install -r requirements.txt
```

└── 订单桌访合并/                      # 本工具
